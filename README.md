# Apify actors in n8n: import-ready workflows

Three n8n workflows that run a paid [Apify](https://apify.com) Actor with the official Apify node (`@apify/n8n-nodes-apify`) and append the dataset to Google Sheets. Import the JSON (n8n: Workflows > Import from file), add an Apify credential and a Google Sheets credential, press Execute.

| Workflow | Actor | File |
|---|---|---|
| TikTok trending hashtags, sounds and creators to Google Sheets (Apify) | [johnveds15~tiktok-trending-scraper](https://apify.com/johnveds15/tiktok-trending-scraper) | [tiktok-trending-to-google-sheets.json](workflows/tiktok-trending-to-google-sheets.json) |
| SEC Schedule 13D / 13G activist and 5% stakes to Google Sheets (Apify) | [johnveds15~sec-13d-13g-ownership-stakes](https://apify.com/johnveds15/sec-13d-13g-ownership-stakes) | [sec-13d-13g-stakes-to-google-sheets.json](workflows/sec-13d-13g-stakes-to-google-sheets.json) |
| SEC Form 4 insider-buying clusters to Google Sheets (Apify) | [johnveds15~sec-form4-insider-clusters](https://apify.com/johnveds15/sec-form4-insider-clusters) | [sec-form4-insider-clusters-to-google-sheets.json](workflows/sec-form4-insider-clusters-to-google-sheets.json) |

## TikTok trending hashtags, sounds and creators to Google Sheets (Apify)

Runs the TikTok Trending Scraper Apify Actor on demand or on a schedule and appends every trending hashtag, sound and creator row to a Google Sheet.

Price (Apify pay per event, read from the Apify API on 2026-11-14):
- Trending item: $0.002 per event

## SEC Schedule 13D / 13G activist and 5% stakes to Google Sheets (Apify)

Runs the SEC 13D Scraper Apify Actor over the latest EDGAR daily indices and appends each ownership-stake record (filer, issuer, percent of class, purpose text) to a Google Sheet.

Price (Apify pay per event, read from the Apify API on 2026-11-14):
- Schedule 13D/13G filing: $0.001 per event
- Ownership stake record delivered: $0.001 per event
- New Schedule 13D (activist stake) delivered: $0.02 per event

## SEC Form 4 insider-buying clusters to Google Sheets (Apify)

Runs the SEC Form 4 Scraper Apify Actor over the last week of EDGAR filings and appends each insider-buying cluster (several insiders buying the same stock) to a Google Sheet.

Price (Apify pay per event, read from the Apify API on 2026-11-14):
- Form 4 filing: $0.0004 per event
- Insider cluster detected: $0.02 per event

## What has and has not been checked (2026-11-14)

- The workflow JSON files were generated by a script and their node parameter names were read from the published `@apify/n8n-nodes-apify` 0.9.0 package source (operation `Run actor and get dataset`, node typeVersion 2). A script then checked each workflow's Apify-node parameters against that package's property definitions: no unknown parameters, every required one present. The workflows were **not** imported into a running n8n instance (a full n8n install was attempted and failed on this server), so the Google Sheets and Code nodes follow documented n8n schemas but have not been executed.
- Not done: a fresh Actor run through n8n. On 2026-11-14 the Apify account that owns these Actors had used its monthly free-plan credit, and Apify refused to start any run. Nothing here is a screenshot or output of an Apify Actor run.
- `samples/` holds **real saved runs of the free open-source cores** (not the Actors): [sec-form4-clusters](https://github.com/MegaStretch23/sec-form4-clusters) and [sec-13d-13g-stakes](https://github.com/MegaStretch23/sec-13d-13g-stakes), both from 2026-11-13, plus a table image rendered from each file. The Actors wrap the same parsing code; their dataset field names differ in places (for example the Form 4 Actor emits `insiderCount` and `totalDollar`).
- **TikTok workflow: no sample.** On 2026-11-13 TikTok's Creative Center endpoint refused every anonymous request from our server (see [tiktok-trending-core](https://github.com/MegaStretch23/tiktok-trending-core)), so we have no successful TikTok output to show. The Actor's pricing text says blocked or empty runs are not charged, and the workflow stops with an error when the Actor returns zero items instead of writing an empty sheet.
- Each workflow sets *Maximum Cost per Run* on the Apify node ($0.50 TikTok, $1.00 for each SEC workflow).
